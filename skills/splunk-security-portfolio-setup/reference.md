# Splunk Security Portfolio Coverage

The executable `catalog.json` is the source of truth for product names, aliases,
status, routes, and coverage notes. The table below is generated from that
catalog. Run `scripts/render_reference_table.py --write` after catalog edits and
`scripts/render_reference_table.py --check` in validation.

Current Enterprise Security terminology receives explicit identities for ES
Essentials, ES Premier, native SOAR, UEBA, Automated Threat Analysis, the
Malware Reversing and Phishing Analysis agents, Security AI Assistant, and
Federated Analytics. This avoids conflating the ES Essentials edition with the
separate Splunk Security Essentials app.
